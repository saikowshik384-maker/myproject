# Village Search System

A full-stack village search application built using:

* React.js
* Node.js
* Express.js
* Prisma ORM
* PostgreSQL
* Neon Database

## Features

* Search villages dynamically
* Pagination support
* Full Andhra Pradesh dataset
* REST API backend
* React frontend UI

## Technologies Used

* React
* Express
* Prisma
* PostgreSQL
* Neon
* GitHub
